## `src/ghostbytes/crypto/config.py`

The following table documents every module-level constant and the `CryptoConfig` class defined in `config.py`.

| Kind            | Name                                           | Default or value                                                                                                                                                                                                                 | Description                                                                                                                                                                                                                                             |
| --------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Constant        | `AVAIL_HASH`                                   | `SHA3_512`, `SHA3_256`, `SHA512`, `SHA256`, `BLAKE2b`, `BLAKE2s`, `md5`                                                                                                                                                          | Hash implementations accepted by the configuration. The order corresponds to `AVAIL_HASH_STR`.                                                                                                                                                          |
| Constant        | `AVAIL_HASH_STR`                               | `sha3_512`, `sha3_256`, `sha512`, `sha256`, `blake2b`, `blake2s`, `md5`                                                                                                                                                          | String names used in the GUI and serialized `.conf` files.                                                                                                                                                                                              |
| Constant        | `AVAIL_ALG`                                    | `aes`, `rsa-oaep`, `extended_oaep`, `ML-KEM-768`, `ML-KEM-1024`                                                                                                                                                                  | Algorithm identifiers accepted by `CryptoConfig` and configuration import.                                                                                                                                                                              |
| Constant        | `AVAIL_SIGN_ALG`                               | `RSA-PSS`, `ML-DSA-44`, `ML-DSA-65`, `ML-DSA-87`                                                                                                                                                                                 | Signing algorithms exposed by the signing tools and benchmark. These are not `CryptoConfig` encryption algorithms.                                                                                                                                      |
| Constant        | `AVAIL_RANDOM_STR`                             | `os.urandom`, `cryptodome_random`, `random lib (python)`, `secrets_random`, `/dev/urandom (*nux only)`, `/dev/random (*nux only)`, `/dev/urandom (dd, out file only) (*nux only)`, `/dev/random (dd, out file only) (*nux only)` | Random-source names accepted by the configuration. Some entries are Unix-only.                                                                                                                                                                          |
| Constant        | `ENCRYPTED_SUFFIX`                             | `.enc`                                                                                                                                                                                                                           | Filename suffix used for encrypted output files.                                                                                                                                                                                                        |
| Constant        | `RSA_KEY_OUT_FORMAT`                           | `PEM`, `DER`, `OpenSSH`                                                                                                                                                                                                          | RSA key serialization formats exposed by the application.                                                                                                                                                                                               |
| Constant        | `COMMON_RSA_SIZE`                              | `2048`, `4096`, `8192`                                                                                                                                                                                                           | Common RSA key sizes offered by the key-generation interface.                                                                                                                                                                                           |
| Constant        | `RSA_SIZE_WARNING_THRESHOLD`                   | `4096`                                                                                                                                                                                                                           | RSA key size above which the application warns that generation or use may take longer.                                                                                                                                                                  |
| Constant        | `OVERWRITE_OPTIONS`                            | `random`, `zero`, `one`, `gutmann`                                                                                                                                                                                               | File-overwrite patterns available to the secure-delete feature.                                                                                                                                                                                         |
| Constant        | `RANDOM_SALT_SIZE`                             | `64`                                                                                                                                                                                                                             | Standard salt length used by configuration workflows, in bytes.                                                                                                                                                                                         |
| Class           | `CryptoConfig`                                 | `CryptoConfig()`                                                                                                                                                                                                                 | Stores the algorithm, AES-GCM envelope settings, KDF parameters, hash selection, random source, and salt used by an encryption or decryption operation.                                                                                                 |
| Class attribute | `CryptoConfig.algorithm`                       | `AVAIL_ALG[0]` (`aes`)                                                                                                                                                                                                           | Algorithm identifier selected for the operation. Must be one of `AVAIL_ALG` when importing a configuration.                                                                                                                                             |
| Class attribute | `CryptoConfig.store_iv`                        | `append`                                                                                                                                                                                                                         | Controls whether the AES-GCM nonce and authentication tag are appended to or prepended to the ciphertext. Valid values are `append` and `prepend`.                                                                                                      |
| Class attribute | `CryptoConfig.mac_len`                         | `16`                                                                                                                                                                                                                             | AES-GCM authentication-tag length in bytes. Configuration import accepts values from `4` through `16`.                                                                                                                                                  |
| Class attribute | `CryptoConfig.kdf_salt`                        | Fixed placeholder byte string                                                                                                                                                                                                    | Salt supplied to Argon2id. Generate a unique random salt before encryption and preserve it in the exported configuration. **IT IS RECOMMENDED TO CHANGE THIS VALUE BEFORE ENCRYPTION AND EXPORT THE CONFIGURATION instead of using the default value.** |
| Class attribute | `CryptoConfig.kdf_time_cost`                   | `16`                                                                                                                                                                                                                             | Argon2id time-cost parameter. It must be at least `1` when importing a configuration.                                                                                                                                                                   |
| Class attribute | `CryptoConfig.kdf_memory_cost`                 | `128 * 1024` (`131072` KiB)                                                                                                                                                                                                      | Argon2id memory-cost parameter stored in KiB. The GUI displays this setting in MB.                                                                                                                                                                      |
| Class attribute | `CryptoConfig.kdf_parallelism`                 | `8`                                                                                                                                                                                                                              | Argon2id parallelism parameter. It must be at least `1` when importing a configuration.                                                                                                                                                                 |
| Class attribute | `CryptoConfig.hash_func`                       | `AVAIL_HASH[0]` (`SHA3_512`)                                                                                                                                                                                                     | Hash implementation used by RSA-OAEP modes and serialized using its matching name from `AVAIL_HASH_STR`.                                                                                                                                                |
| Class attribute | `CryptoConfig.rand_func`                       | `AVAIL_RANDOM_STR[0]` (`os.urandom`)                                                                                                                                                                                             | Random source used by configuration salt generation and supported random-data operations.                                                                                                                                                               |
| Method          | `CryptoConfig.generate_random_salt(length=64)` | Returns `bytes`                                                                                                                                                                                                                  | Generates a salt with the configured random source, stores it in `kdf_salt`, and returns the generated bytes.                                                                                                                                           |
| Method          | `CryptoConfig.export_file(path)`               | Writes a `.conf` file                                                                                                                                                                                                            | Writes the current configuration to an INI-style file with a `[CryptoConfig]` section. The salt is encoded as Base64.                                                                                                                                   |
| Class method    | `CryptoConfig.import_file(path)`               | Returns `CryptoConfig`                                                                                                                                                                                                           | Reads and validates a `[CryptoConfig]` section, restores the saved settings, decodes the Base64 salt, and returns a configuration instance.                                                                                                             |

The encryptor and decryptor must use matching values for the relevant configuration fields, especially `algorithm`, `store_iv`, `mac_len`, the KDF settings, and `kdf_salt`.

The `ML-DSA` signature algorithm does not use `CryptoConfig`, while the RSA signature algorithm uses only the `hash_func` field in `CryptoConfig`
