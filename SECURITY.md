# Security Policy

GhostBytes is beta software for desktop file encryption and data security. It
handles sensitive files, passwords, private keys, and encrypted data, so please
report suspected vulnerabilities responsibly.

## Supported Versions

Security fixes are prioritized for the latest released version and the current
default branch. Older releases may not receive backported fixes. Check the
project changelog and release information when deciding whether an update is
available.

## Reporting a Vulnerability

Do not report vulnerabilities through public GitHub issues, pull requests, or
discussion posts. Use GitHub's private vulnerability reporting or security
advisory feature for this repository when available. If that feature is not
available, contact the project maintainers through a private channel before
disclosing details publicly.

Please include, when safe to share:

- the affected version, platform, and Python version;
- clear reproduction steps or a minimal proof of concept;
- the expected and observed behavior;
- the likely impact and any required configuration; and
- logs or files needed to reproduce the issue, with passwords, private keys,
  plaintext, and personal data removed.

Do not include real secrets or user data in a report. If a report contains
particularly sensitive material, describe it first and wait for instructions
before sending attachments.

## Response and Disclosure

Maintainers will acknowledge reports when possible, investigate the issue, and
coordinate a fix or mitigation with the reporter. Timelines depend on severity,
reproducibility, and maintainer availability.

Please allow time for investigation and release preparation before making the
issue public. Coordinated disclosure details should be agreed with maintainers;
do not publish an exploit or full reproduction while users remain exposed.

## Security Scope and Limitations

Reports are especially valuable for issues involving:

- encryption, decryption, authentication, key derivation, or random values;
- private-key, password, plaintext, or configuration exposure;
- ciphertext integrity, tampering, or unsafe deserialization;
- path traversal, unintended file access, or destructive file operations;
- dependency vulnerabilities that affect GhostBytes; and
- GUI behavior that exposes or mishandles sensitive data.

GhostBytes does not guarantee protection against malware, compromised operating
systems, memory extraction, insecure backups, hardware failure, or every form
of storage recovery. Secure-delete and overwrite operations cannot guarantee
permanent erasure on all filesystems, SSDs, snapshots, or backups.

The GUI is completely generated by AI. This does not reduce the security
standard for the code: AI-generated behavior should be reported and reviewed
like any other production code.
